# UX-структура режимов и выбор вариантов компонентов

Этапы 5 и 14; переработано в редакциях 0.2.0–0.2.4 (Р-55…Р-63). Опора: SPEC.md, §6–10; токены — TOKENS.md.

Направление: «Minimalism & Swiss Style» для корпоративных панелей, подтверждено базой навыка ui-ux-pro-max. В 0.2 плотность снижена с 8/10 до 6/10 по замечанию заказчика («страница перегружена»), затем часть содержания возвращена в «Сводку» на полную ширину (Р-58).

## 0. Каркас страницы (1440 × 900)

```
┌ Шапка 56 ───────────────────────────────────────────────────────────────────────────────────────┐
│ ◯ CRM                      │ Сводка  График работ  Ближайшие сроки  Статусы  Вехи │ на 28.09.2026 │ ⎙ │ ☾ │
│   ───────────────────      │ (активная вкладка — подчёркивание)                   │               │   │   │
│   Квантовый сенсор ИИМ ЯМГ (Электроприбор)                                                      │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
│ Панель инструментов (кроме «Сводки»): поиск · участник · раздел · [срезы / повестка]             │
│ Заголовок режима: вывод одной фразой + показатели режима                                        │
│ Содержимое режима на всю ширину, поля 32                                   │ Карточка работы 560 │
│ Подвал: источник данных, календарь                                                               │
```

- **Переключатель режимов**: `role="tablist"`; стрелки ←/→ переходят по вкладкам, Enter и пробел активируют.
- **Дата «на ДД.ММ.ГГГГ»** в шапке — дата расчёта признаков; при `?today` в подсказке указано «задана параметром ссылки». На ширине ≤ 1100 px дата переносится в первую фразу «Сводки».
- **Печать** (⎙): текущий режим на A4 в альбомной ориентации, в светлой теме; из окна повестки печатается только её текст.
- **Карточка работы**: `role="dialog"`, `aria-modal="false"`. Закрывается по Esc; фокус переходит на заголовок, при закрытии возвращается на исходный элемент.
- **Одно акцентное действие на экран** — синяя кнопка только в «Ближайших сроках» («Повестка оперативки»), в окне повестки («Скопировать») и в форме закрытия работы («Отметить выполненной»). Остальные действия — ссылки и нейтральные кнопки.

## 1. Принципы редакции 0.2

| Принцип | Реализация |
|---|---|
| Наименование вместо номера | Краткие наименования из `CONFIG.SHORT`. Номер пункта — только в карточке («№ 2.1.7 по План-графику»), в подсказке и в формате письма (Р-55) |
| Вывод раньше данных | Каждый режим начинается фразой-выводом: «Этап 1 идёт с отставанием: 2 обязательства просрочены», «Следующая веха — 30.09.2026…» (Р-60) |
| Статус — точка и слово | Цвет — семантика «Важного», слово — смысл; заливочные бейджи убраны (Р-56) |
| Сроки словами | «просрочено на 13 дней», «через 2 дня»; в таблицах — «−13 дн.» |
| Роли участников | Первым указан ответственный (Электроприбор), участники — пометкой «+ ФТИ, ИХС», «+ Заказчик» (Р-61) |
| Полная ширина | Содержимое заполняет экран, как «График работ» (Р-58) |

## 2. Сводка (В1)

Вопрос руководителя «где проект и что горит» — ответ за 10 секунд, без прокрутки: первый экран на 1440 × 900 показывает вывод, 5 показателей и «Сроки этапа».

1. Вывод одной фразой и строка пояснения.
2. Пять показателей; нажатие ведёт в режим с подробностями.
3. «Сроки этапа» — обязательства по неделям (выполнено / просрочено / предстоит), вехи с подписями по дорожкам, «сегодня».
4. Две колонки: слева «Требует внимания» (до 5 работ, причина словами) и «Исполнитель и соисполнители»; справа «Путь к демонстрации образца» — 8 шагов списком с состоянием переходов.
5. «Ход работ по разделам» — 4 раздела в строку.

**В3** отличается порядком: путь к демонстрации крупно, горизонтально, сразу после вывода. **В2** начинается с «Графика работ» с полосой показателей.

## 3. График работ

- Колонки: работа · исполнитель · срок и остаток · статус · шкала.
- Строки разделов показывают итог по текущему отбору.
- Срезы со счётчиками: «Все работы 66», «Просроченные 8», «Путь к демонстрации 8».
- На 1440 × 900 видно не менее 25 строк (Р-49); прокрутка внутри таблицы, заголовок закреплён.

## 4. Ближайшие сроки

- Шесть плиток периодов с числом работ и границами дат; нажатие раскрывает период и переходит к нему.
- Периоды «Позднее» и «Выполнено» свёрнуты по умолчанию.
- В строке: работа (у подпозиции — «в составе «группы»»), исполнитель, срок, «Осталось», статус и прошедшая контрольная дата.
- «Повестка оперативки» — окно с двумя форматами (SPEC §6).

## 5. Статусы

- Полоса распределения по группам статусов над колонками.
- 7 колонок словаря в 1440 px; колонки прокручиваются независимо.
- Просроченная карточка отмечена красной кромкой; унаследованный статус — пометкой «статус по группе».

## 6. Вехи

- Полоса дат: грозди работ по дню срока (цвет — статус, красный — просрочено), подписанные вехи, «сегодня».
- «Вехи этапа»: дата, название, «через N дней / пройдена», готовность «к вехе выполнено X из Y · просрочено N»; следующая веха выделена.
- Справа — работы выбранной даты.

## 7. Карточка работы

Порядок сверху вниз — от действия к справке:
1. Краткое наименование, «№ N по План-графику».
2. Статус, срок словами, контрольная дата; для шага пути — «Шаг N из 8» и переходы к соседним шагам; смена статуса (1 нажатие; «Закрыто» — форма документа, 2 нажатия).
3. «Входит в группу» или «Состав группы».
4. Сроки; официальное наименование; «Ответственность»; представляемые документы; отметка «Важного»; комментарий; связанные работы.
5. «Основание и примечание План-графика» — свёрнуто.

## 8. Выбор вариантов ключевых компонентов (этап 14, пересмотрено в 0.2)

| Компонент | Варианты | Отобран | Обоснование |
|---|---|---|---|
| Строка «Графика работ» | а) полоса во всю высоту строки с текстом; б) тонкая полоса 12 px, текст в колонках; в) полоса 20 px с номером | **б** | Текст не помещается на коротких работах и дублирует колонки. Тонкая полоса оставляет место засечке контрольной даты и штриховке |
| Статус | а) заливочный бейдж; б) точка + слово | **б** (0.2) | Бейджи в каждой строке создавали шум, на который указал заказчик; точка сохраняет цветовую семантику, слово — смысл |
| Плитка показателя | а) число + подпись; б) число + подпись + расшифровка; в) число + спарклайн | **б** | Расшифровка раскрывает «план на сегодня» и «без документа»; спарклайн без истории данных (Р-36) был бы выдуманным рядом |
| Путь к демонстрации | а) таблица; б) горизонтальная нитка шагов; в) вертикальный список шагов | **в** в В1, **б** в В3 | Вертикальный список вмещает название, дату, состояние и исполнителя без сокращений; горизонтальная нитка выразительнее как первый экран В3 |
| Вехи на полосе | а) номера 1–8 с легендой; б) подписи названиями по дорожкам | **б** (0.2.2) | Номера требуют второго взгляда в легенду; заказчик требует названий (Р-55) |
