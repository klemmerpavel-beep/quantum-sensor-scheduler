# Токены оформления · «Орбита»

Этап 6. После этого этапа значения вне таблиц ниже не вводятся (запрет постановки). В CSS токены объявлены как пользовательские свойства на `:root`. Тёмная тема переопределяет их под `:root[data-theme="dark"]`. Для совместимости с публикацией — также под `@media (prefers-color-scheme: dark)` с охраной `:root:not([data-theme="light"])`. Страница всегда явно выставляет `data-theme`, поэтому системная настройка выбор не меняет [Р-39].
Контраст всех пар проверяется скриптом `tools/contrast.py` — результат «ALL PASS». Различимость статусных цветов — валидатором навыка dataviz, см. Р-51.

### 1.2. Статусы — семантика вкладки «Важное» (BRIEF, раздел 4)

| Класс | Статусы словаря | Смысл | Полоса (свет. / тёмн.) | Бейдж: фон / текст (свет.) | Бейдж: фон / текст (тёмн.) |
|---|---|---|---|---|---|
| `closed` | Закрыто | зелёный — закрыто | `#1A7F4B` / `#2E9F60` | `#E3F4EA` / `#0F6B38` | `#12301F` / `#86DDA9` |
| `progress` | В работе, Подготовка материалов | светло-зелёный — идёт по графику | `#7D8C06` / `#B9CC45` | `#EDF6E1` / `#3A6912` | `#1D2B12` / `#B8DE8F` |
| `action` | Ожидаем документ, На согласовании, Нет отметки | оранжевый — требует действия | `#A86E00` / `#E8A33A` | `#FFF0DD` / `#8A4700` | `#3A2410` / `#FFC27A` |
| `overdue` | признак «Просрочено» | красный — просрочено | `#C92A32` / `#F0616A` | `#FDE8E9` / `#AE1C25` | `#3D171A` / `#FFA0A6` |
| `future` | Не начато | нейтральный серый — будущие | `#78818E` / `#788190` | `#EEF0F3` / `#454C57` | `#242833` / `#BAC1CC` |

Состояния окна цепочки [Р-47]:
- `eroding` — цвет `action`;
- `breach` — цвет `overdue`;
- `ok`, `thin`, `overlap` — нейтральные: `--text-2`, штриховка `--border-strong`;
- `done` — `closed`.

### 1.3. Кодирование помимо цвета (обязательно, [Р-51])

- **Статус** — всегда словом: бейдж или столбец «Статус».
- **Форма полосы по статусу**: «Закрыто» — сплошная с глифом ✓ у конца; «Не начато» — контурная (рамка `--border-strong`, фон `--surface-3`); остальные — сплошные.
- **Просроченная часть** — штриховка 45° цветом `overdue` + текст «просрочено N дн.».
- **Производное начало** — сегмент полосы с непрозрачностью `--derived-alpha: 0.35`.
- **Критическая цепочка** — обводка полосы 2 px `--accent` + номер звена «Ц1…Ц8» + текстовая пометка «Цепочка ЛО».

## 4. Форма

| Токен | Значение |
|---|---|
| `--radius-1` | 4px — бейджи, полосы, поля |
| `--radius-2` | 8px — карточки, плитки, панель, кнопки |
| `--shadow-1` | `0 1px 2px rgba(16, 24, 40, 0.06)` — плитки и карточки |
| `--shadow-2` | `0 8px 24px rgba(16, 24, 40, 0.16)` — боковая панель и окно повестки |
| `--focus` | `outline: 2px solid var(--accent); outline-offset: 2px` — не отключается |
| `--hatch` | `repeating-linear-gradient(45deg, var(--st-overdue) 0 2px, transparent 2px 6px)` |
| `--derived-alpha` | 0.35 |
| Переходы | `--dur: 120ms`, только `background-color`, `border-color`, `transform` у панели. `prefers-reduced-motion: reduce` → `0ms` |

Градиенты (кроме штриховки как текстуры данных), декоративные иллюстрации и третья формула тени запрещены. Наведение меняет только цвет рамки или фона.

## 5. Иконки

Штриховые иконки Lucide (лицензия ISC) встроены инлайн как SVG: `stroke-width: 2`, `stroke: currentColor`, размеры 16 и 20 px. Набор:
- chevron-right, chevron-down, x;
- sun, moon;
- search, copy, check;
- alert-triangle, clock, flag, file-text, rotate-ccw.
