# Сценарий показа коллегам · CRM «Квантовый сенсор ИИМ ЯМГ (Электроприбор)»

- **Длительность**: 8–10 минут показа и 5 минут вопросов.
- **Аудитория**: коллеги, не знакомые с номерами пунктов План-графика.
- **Цель**: показать, что по одной ссылке видно состояние этапа 1, риски срыва демонстрации лабораторного образца и вопросы к Исполнителю на оперативку.

## Подготовка (за 5 минут до показа)

1. Открыть ссылку для показа: https://klemmerpavel-beep.github.io/quantum-sensor-scheduler/?today=2026-10-06
   - Данные — редакция «Важного» на 06.10.2026 (Р-75). Параметр `today=2026-10-06` фиксирует дату редакции: цифры совпадают с этим сценарием.
   - Без параметра страница считает от текущей даты; после 06.10.2026 под датой в шапке появится «отметки на 06.10.2026», а работы со сроком после этой даты без отметки — «срок прошёл, нет подтверждения» (Р-74).
2. Масштаб браузера — 100 %, окно на весь экран; для проектора — светлая тема (кнопка ☾/☀ в шапке).
3. Запасной вариант без интернета — файл `dist/crm-ymg-iim-stage1-offline.html` на ноутбуке; к адресу добавьте `?today=2026-10-06`.

## Что изменилось с редакции 28.09.2026

| Показатель | 28.09.2026 | 06.10.2026 |
|---|---|---|
| Выполнено | 10 из 47 | 10 из 47: закрыто «Техзадание для ИХС» (01.10), переоткрыт п. 2.1.8 |
| Просрочено | 2 | 8 — все со сроком 30.09, кроме «Закупки» (15.09) |
| Путь к демонстрации | «резерв расходуется», срыв с 01.10.2026 | «угроза срыва»: закупка и договоры с соисполнителями не закрыты |
| До демонстрации | 44 рабочих дня | 38 рабочих дней |

Что сказать: «Срыв, о котором предупреждала прошлая редакция, наступил: закупка не закрыта к 01.10. Из 8 обязательств недели 30.09 выполнено одно».

## Частые вопросы

| Вопрос | Ответ |
|---|---|
| Откуда данные? | План-график этапа 1 и вкладка «Важное», редакция на 06.10.2026 (прежняя редакция 28.09.2026 — в архиве). Данные сверены с исходной таблицей План-графика: расхождений нет |
| Можно ли отмечать выполнение? | Да: в карточке меняется статус, «Закрыто» требует реквизита документа. Отметки хранятся только в этом браузере и другим не видны; кнопка «Отметки в этом браузере» в подвале показывает их списком и даёт текст для письма. Общее хранение — следующий этап (Р-41) |
| Почему 47, а не 71? | 71 позиция План-графика включает разделы, группы и внутренние подпозиции. 47 — обязательства перед Заказчиком; внутренние подпозиции учитываются в своей группе |
| Что такое «резерв»? | Запас рабочих дней между сроком шага и сроком следующего шага пути к демонстрации (по производственному календарю РФ, включая переносы 2026–2027 годов) |
| Почему некоторые шаги соединены пунктиром? | Их сроки в План-графике пересекаются (работы идут параллельно). Мы направили вопрос Исполнителю — см. `docs/QUESTIONS.md` |
| Кто видит страницу? | Ссылка на GitHub Pages открыта без авторизации; для работы с реальными данными продукт переносится во внутренний контур (Р-42). Для этого готов файл без сетевых запросов |
| Что дальше? | Общее хранение отметок и доступ по ролям (Р-41); размещение во внутреннем контуре (Р-42); ответы Исполнителя по П-17 и С-3 |
