# Сценарий показа коллегам · CRM «Квантовый сенсор ИИМ ЯМГ (Электроприбор)»

- **Длительность**: 8–10 минут показа и 5 минут вопросов.
- **Аудитория**: коллеги, не знакомые с номерами пунктов План-графика.
- **Цель**: показать, что по одной ссылке видно состояние этапа 1, риски срыва демонстрации лабораторного образца и вопросы к Исполнителю на оперативку.

## Подготовка (за 5 минут до показа)

1. Открыть в браузере ссылку для показа: https://klemmerpavel-beep.github.io/quantum-sensor-scheduler/?today=2026-09-28
   - Параметр `today=2026-09-28` фиксирует дату редакции План-графика: цифры совпадают с этим сценарием.
   - Без параметра страница считает от текущей даты. 29.09.2026 меняются только отсчёты: «43 рабочих дня» до демонстрации, «92 дня» до окончания этапа.
2. Масштаб браузера — 100 %, окно на весь экран; для проектора — светлая тема (кнопка ☾/☀ в шапке).
3. Запасной вариант без интернета — файл `dist/crm-ymg-iim-stage1-offline.html` на ноутбуке. Он открывается двойным щелчком, для надёжности добавьте к адресу `?today=2026-09-28`.

## Частые вопросы

| Вопрос | Ответ |
|---|---|
| Откуда данные? | План-график этапа 1 и вкладка «Важное», редакция на 28.09.2026. Данные сверены с исходной таблицей План-графика: расхождений нет |
| Можно ли отмечать выполнение? | Да: в карточке меняется статус, «Закрыто» требует реквизита документа. Отметки хранятся только в этом браузере и другим не видны. Общее хранение — следующий этап (Р-41) |
| Почему 47, а не 71? | 71 позиция План-графика включает разделы, группы и внутренние подпозиции. 47 — обязательства перед Заказчиком; внутренние подпозиции учитываются в своей группе |
| Что такое «резерв»? | Запас рабочих дней между сроком шага и сроком следующего шага пути к демонстрации (по производственному календарю РФ, включая переносы 2026–2027 годов) |
| Почему некоторые шаги соединены пунктиром? | Их сроки в План-графике пересекаются (работы идут параллельно). Мы направили вопрос Исполнителю — см. `docs/QUESTIONS.md` |
| Кто видит страницу? | Ссылка на GitHub Pages открыта без авторизации; для работы с реальными данными продукт переносится во внутренний контур (Р-42). Для этого готов файл без сетевых запросов |
| Что дальше? | Общее хранение отметок и доступ по ролям (Р-41); размещение во внутреннем контуре (Р-42); ответы Исполнителя по П-17 и С-3 |
